# edu_games
🎮 Edu Games

Edu Games adalah kumpulan permainan edukasi yang dirancang untuk membantu proses belajar menjadi lebih interaktif, menyenangkan, dan menarik. Game ini dapat digunakan sebagai media pembelajaran maupun sebagai sarana latihan untuk menguji pemahaman pengguna terhadap materi tertentu.

📚 Tentang Edu Games

Edu Games menggabungkan unsur pendidikan dan permainan (game) sehingga pengguna dapat belajar sambil bermain.

Tujuan utama proyek ini adalah:

Membuat proses belajar menjadi lebih menyenangkan.

Membantu pengguna memahami materi melalui permainan interaktif.

Menyediakan media pembelajaran yang sederhana dan mudah digunakan.

Dapat dikembangkan dan disesuaikan dengan kebutuhan pembelajaran.

🚀 Penggunaan

Source code dari Edu Games dapat digunakan, dipelajari, dimodifikasi, dan dikembangkan untuk kebutuhan pribadi maupun pembelajaran.

Jika menggunakan atau mengembangkan kembali source code dari proyek ini, harap tetap mencantumkan sumber/original repository sebagai bentuk apresiasi kepada pembuatnya.

Jika terdapat bagian kode, desain, aset, atau komponen dari sumber lain, harap tetap mencantumkan atribusi sesuai dengan lisensi atau ketentuan dari sumber tersebut.

⚖️ Ketentuan

Penggunaan source code diperbolehkan selama:

Tidak menghapus atribusi atau kredit sumber asli.

Mencantumkan sumber repository jika menggunakan atau mendistribusikan kembali source code.

Tetap menghormati lisensi dari library, aset, font, gambar, ikon, atau komponen pihak ketiga yang digunakan dalam proyek.
